# AOSAR
Problem statement:
Inside a service facility, a small mobile robot scanner with three omnidirectional wheels must
repeatedly approach coloured Kung-Fu Scrolls to check their legitimacy. The mobile robot must
reach each Kung-Fu Scroll in the correct orientation and position before the next operation can
begin. The surroundings may not always offer the robot a perfectly predictable starting
orientation, so the machine must determine its own alignment and make controlled corrections
before settling into position. The service Engineer requires the mobile robot to be 400mm away
when settling into position for a Red Kung-Fu Scroll , whereas 600mm away when faced with a
blue Kung-Fu Scroll.
